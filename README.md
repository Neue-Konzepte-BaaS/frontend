# BaaS — Frontend

React frontend for **Bauer as a Service (BaaS)**, a university project ("Neue Konzepte").

The backend (Go + PostgreSQL) lives in a separate repo:
<https://github.com/Neue-Konzepte-BaaS/backend>

## Status

Scaffolded: React Router v8 (framework mode, **SPA**) + Tailwind v4 + TypeScript.
See `AGENT.md`, `context.md`, and `architecture.md` for product and code context.

## Getting started

```sh
npm install
npm run dev        # start the dev server
npm run typecheck  # type-check the app
npm run build      # production build
```
